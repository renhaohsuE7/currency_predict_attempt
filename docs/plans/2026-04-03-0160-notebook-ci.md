# Plan #0160: Notebook CI (nbstripout + papermill)

- **Date**: 2026-04-03
- **Status**: completed
- **Module**: notebooks/, .github/workflows/
- **Priority**: P2

## 目標

確保 Jupyter Notebooks outputs 在 commit 前自動 strip，並在 CI 中驗證。

## 現狀

- 4 個 notebooks 在 `notebooks/`，部分含大量 output（總計 ~1.7 MB）
- **無** nbstripout 配置
- **無** 自動化 notebook 驗證

## 設計決策

| 問題 | 決策 |
| --- | --- |
| Output stripping | nbstripout git filter + pre-commit hook |
| 執行驗證 | CI 中 `nbstripout --verify` 確認 outputs 已 strip；nbformat 驗證 notebook 結構 |
| 完整執行 | 不在 CI 執行 notebook（需 yfinance 網路 + GPU），僅驗證結構 |
| CI 整合 | 新增 `notebooks` job 到 `ci.yml` |

## 實作摘要

### 新增/修改檔案

| 檔案 | 動作 | 說明 |
| --- | --- | --- |
| `.gitattributes` | **新增** | `*.ipynb filter=nbstripout` git filter |
| `.pre-commit-config.yaml` | **新增** | nbstripout pre-commit hook |
| `pyproject.toml` | 修改 | `notebook = ["nbstripout>=0.9.0", "papermill>=2.6.0"]` optional dep |
| `.github/workflows/ci.yml` | 修改 | 新增 `notebooks` job：`nbstripout --verify` + nbformat validation |

### CI notebook job

```yaml
notebooks:
  runs-on: ubuntu-latest
  steps:
    - Verify notebooks are output-stripped (nbstripout --verify)
    - Validate notebook structure (nbformat.read)
```
